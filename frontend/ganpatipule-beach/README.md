# 🛕 Ganpatipule Beach: Sacred Shores

## Overview
A dedicated explorer for **Ganpatipule Beach**, Maharashtra's unique destination combining pristine Konkan beaches with the 400-year-old Swayambhu Ganesh Temple. Experience the intersection of spirituality and coastal beauty.

## Features
- **Heritage Timeline:** 6 key historical events from temple discovery (1600s) to modern tourism hub.
- **Sacred Architecture:** Temple features, daily rituals, meditation caves, and sacred trees.
- **Beach Features:** Clean white sand, gentle waves, tide pools, and spectacular sunsets.
- **Konkan Culture:** Traditional cuisine (Amboli, Sol Kadhi, Modak) and festivals (Ganesh Chaturthi, Narali Purnima).

## File Structure
- `index.html`: Semantic layout with five tabbed sections.
- `style.css`: Saffron/terracotta spiritual theme with full dark/light mode support.
- `script.js`: Tab management, lightbox modal, Journey API integration.
- `data.js`: Comprehensive datasets for heritage timeline, temple features, and culture.
- `components.js`: Safe DOM rendering functions (zero innerHTML).

## Accessibility
- Fully keyboard navigable tabs and gallery.
- ARIA attributes for screen readers.
- High contrast ratios in both light and dark themes.
