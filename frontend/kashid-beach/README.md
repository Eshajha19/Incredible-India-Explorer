
# 🏖️ Kashid Beach: White Sands of Raigad

## Overview
A dedicated explorer for **Kashid Beach**, Maharashtra's cleanest beach with pristine white sand, dramatic black basalt rock formations, and distinctive casuarina groves along the Konkan coast.

## Features
- **Natural Features:** 6 cards covering white sand, basalt rocks, casuarina groves, clear waters, birdlife, and sunsets.
- **Activities:** Swimming, horse rides, water sports, photography, and beach shack cuisine.
- **Nearby Attractions:** Harihareshwar Temple, Murud Janjira Fort, Phansad Wildlife Sanctuary.
- **Lightbox Gallery:** 8 captioned images with keyboard navigation.

## File Structure
- `index.html`: Semantic layout with 5 tabbed sections.
- `style.css`: Sandy white/ocean blue theme with dark/light mode.
- `script.js`: Tab management, lightbox, Journey API.
- `data.js`: Datasets for nature, activities, nearby attractions, and gallery.
- `components.js`: Safe DOM rendering (zero innerHTML).

## Accessibility
- Keyboard navigable tabs and gallery.
- ARIA attributes for screen readers.
- Focus indicators on interactive elements.
