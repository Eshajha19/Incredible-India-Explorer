# 🌙 Kudle Beach: Gokarna's Crescent Paradise

## Overview
A dedicated explorer for **Kudle Beach**, one of Gokarna's five pristine beaches in Karnataka. Known for its perfect crescent shape, yoga retreats, Ayurvedic centers, and spiritual coastal setting along the sacred Karavali coast.

## Features
- **Natural Setting:** 6 cards covering the crescent shape, cliff-top setting, and rock pool ecology.
- **Wellness & Culture:** Yoga shalas, Ayurvedic retreats, meditation centers, sattvic cuisine, and spiritual workshops.
- **Coastal Highlights:** Traditional fishing villages, wooden boats, shell beaches, and turtle nesting sites.
- **Nearby Attractions:** Om Beach, Half Moon Beach, Paradise Beach, Mahabaleshwar Temple.

## File Structure
- `index.html`: Semantic layout with 5 tabbed sections.
- `style.css`: Zen earth/turquoise theme with full dark/light mode.
- `script.js`: Tab management, lightbox, Journey API.
- `data.js`: Datasets for nature, wellness, coastal highlights, and gallery.
- `components.js`: Safe DOM rendering (zero innerHTML).

## Accessibility
- Keyboard navigable tabs and gallery.
- ARIA attributes for screen readers.
- Focus indicators on interactive elements.
